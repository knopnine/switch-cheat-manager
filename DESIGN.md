# Switch Cheats Manager

Approved direction: modern desktop workspace, neutral surfaces and a restrained red accent. Follow the system light/dark preference with an explicit override. Compact utility typography; system sans for controls and system monospace for codes. Apply antislop throughout the work.

The library and build navigation select the file; the editor is the dominant surface. Red identifies primary commit actions and active destinations. Use flat surfaces and subtle separators, four-pixel control radii, no decorative imagery, no dashboard statistics. Motion is limited to short control feedback and respects reduced motion. Accessibility, readable contrast, recovery states, and narrow-screen reflow are required.
